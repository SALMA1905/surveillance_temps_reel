Real-Time Surveillance System

A real-time surveillance and detection system developed using Python, OpenCV, TensorFlow/Keras, and Deep Learning.

📌 Project Overview

This project focuses on detecting people in real time using a camera or video stream.

The system processes video frames using computer vision techniques and a trained deep learning model to perform automatic detection.

This project was developed as part of my Final Year Project (PFE).

🎯 Objectives

- Detect people from images and video streams
- Process video frames in real time
- Apply computer vision techniques using OpenCV
- Train and use a deep learning model for detection
- Experiment with different model configurations using Jupyter Notebook

🛠️ Technologies

- Python
- OpenCV
- TensorFlow / Keras
- Jupyter Notebook
- Deep Learning
- Computer Vision

⚙️ How to Run

1. Clone the repository

git clone https://github.com/SALMA1905/surveillance_temps_reel.git
cd surveillance_temps_reel

2. Install the required libraries

pip install opencv-python tensorflow jupyter

3. Run the detection system

python "en temps réel.py"

Make sure that the trained model and required files are available in the project directory.
