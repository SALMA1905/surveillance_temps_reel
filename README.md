Real-Time Surveillance System

A real-time surveillance and detection system developed using Python, OpenCV, and a trained deep learning model.

📌 Project Overview

This project focuses on detecting people in real time using a camera or video stream.

The system uses computer vision techniques to process video frames and a trained deep learning model to perform detection.

🛠️ Technologies

- Python
- OpenCV
- TensorFlow / Keras
- Jupyter Notebook
- Deep Learning
- Computer Vision

📂 Project Structure

- `avec vidéo.py` — Real-time detection using video
- `en temps réel.py` — Real-time detection
- `pfe.ipynb` — Model training and experimentation
- `model_pfe.h5` — Trained deep learning model
- `Data_train.rar` — Training dataset

⚙️ How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Make sure the trained model is available.
4. Run the appropriate Python script.

Example:

```bash
python "en temps réel.py"
